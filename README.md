# Glow-Haven-
A beautifully crafted, fully responsive premium landing page designed for a modern skincare salon. This project focuses on high-end visual aesthetics, clean typography, and intuitive user navigation to maximize client bookings.
- Responsive Design: Fluid layout that transitions seamlessly from large desktop monitors to mobile screens.
  - Modern UI Elements: Elegant navigation, custom service cards, high-quality image cards, and styled contact forms.
- Performance Optimized: Clean semantic HTML structure and optimized CSS for quick loading times.

## 🛠️ Tech Stack & Concepts Used

- **HTML5:** Semantic markup (`<header>`, `<main>`, `<section>`, `<footer_>`) for strong SEO and accessibility.
- **CSS3 Layouts:** Flexbox and CSS Grid utilized for dynamic, adaptable section structures.
- **Advanced CSS styling:** Precision spacing, hover effects, and form input styling.
